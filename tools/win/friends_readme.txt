BATTLEFIELD — как играть

1. Распакуй архив в любую папку и запусти Battlefield.exe.
   Windows может показать «Система Windows защитила ваш компьютер» — это потому, что игра
   не подписана. Нажми «Подробнее» → «Выполнить в любом случае».
2. Зайди в сеть Radmin VPN, куда пригласил хост.
3. В игре: введи имя → «Подключиться» → IP хоста из Radmin (вида 26.x.x.x).
   Если хостишь сам — «Создать игру» и разреши доступ в брандмауэре (частные сети).

У всех должна быть ОДНА версия игры, иначе хост не пустит.
Новая версия всегда тут (тот же архив):
https://github.com/Yotonick/battlefield/releases/latest/download/Battlefield-Windows.zip

Управление: WASD — ходьба, Shift — бег, Ctrl — присед, Пробел — прыжок,
ЛКМ — стрельба, ПКМ — прицел, R — перезарядка, Tab — счёт, Esc — меню.
