# Battlefield (рабочее название)

Low-poly военный FPS для компании друзей: 2–6 игроков по LAN (Radmin VPN), бои ~10 на 10 с ботами.
Движок — **Godot 4.7** (обычная версия, не .NET), язык — **GDScript со строгой типизацией**.

## Как запустить

### Windows, одним кликом (с автообновлением)
1. Положить `setup.bat` в папку, где будет игра (можно непустую), и запустить. Он сам:
   ставит Git (через winget, если его нет), скачивает игру с GitHub, скачивает Godot в `.engine\`,
   готовит ресурсы и делает ярлык **Battlefield** на рабочем столе.
2. Дальше играть через **`play.bat`** (или ярлык): при каждом запуске он скачивает обновления с GitHub
   и запускает игру. Аргументы передаются в игру: `play.bat --host --name=Хост --team=1`.
3. `test_2_windows.bat` — два окна на одном ПК (хост за Синих + гость за Красных).

| Файл | Что делает |
|---|---|
| `setup.bat` | первая установка (копирует себя во временную папку, поэтому git может его обновлять) |
| `play.bat` | обновление + запуск. **Верх файла до строки «ВАЖНО» менять нельзя** — файл обновляет сам себя на ходу |
| `test_2_windows.bat` | хост + гость на одном ПК |
| `build_for_friends.bat` | ручная сборка `build\Battlefield-Windows.zip` (первый раз качает шаблоны ~1.3 ГБ) |
| `tools/win/config.bat` | версия Godot и адрес репозитория — **единственное место**, где они записаны |
| `tools/win/run.bat`, `install_godot.bat`, `import.bat`, `force_update.bat` | шаги запуска; их можно менять свободно |

Если обычное обновление не прошло (правили файлы руками), `force_update.bat` сохраняет правки в
`git stash` и ставит чистую версию с GitHub. Нет интернета — запускается то, что уже скачано.
Логи — в `logs\`. Сырые ассеты в `models\` Godot и git не трогают (см. `.gitignore`, `models\.gdignore`).

### Сборка для друзей (exe)
После каждого push в `main` GitHub Actions (`.github/workflows/build-windows.yml`) собирает
`Battlefield.exe` и выкладывает в Releases. Постоянная ссылка:
**https://github.com/Yotonick/battlefield/releases/latest/download/Battlefield-Windows.zip**
— друг распаковывает и запускает `Battlefield.exe`, ничего ставить не нужно. Новая версия игры —
тот же архив по той же ссылке. Exe не подписан: Windows SmartScreen попросит «Подробнее → Выполнить в
любом случае». Настройки экспорта — `export_presets.cfg` (пресет «Windows», один exe со встроенным pck).

### Из редактора
1. Открыть Godot 4.7 → *Import* → выбрать `project.godot` из этой папки
   (или `.engine\Godot_v…_win64.exe` после `setup.bat`).
2. Первый запуск редактора импортирует файлы (создаст папку `.godot/` — она в `.gitignore`).
3. **F5** — главное меню: имя, настройки матча (карта, лимит убийств, время раунда),
   «Создать игру» или «Подключиться» по IP.

## Командный бой (TDM, v0.1)
- Две команды: **Синие** (база на западе) и **Красные** (база на востоке).
- **Команду выбирает игрок** — экран выбора появляется при входе; «Авто» отправит туда, где меньше людей.
  Сменить команду — Esc → «Сменить команду» (без штрафа: просто появитесь на базе новой команды).
- **Огня по своим нет**: пули пролетают сквозь союзников.
- Своих видно по цвету (синие/красные бойцы) и по имени над головой — оно видно и сквозь стены.
  Имён врагов нет.
- Раунд: **до 30 убийств или 10 минут** (хост меняет в главном меню). Кто больше набрал к концу
  времени — победил, поровну — ничья. Потом 15 с итогов (все стоят) и новый раунд: счёт с нуля,
  все на базах.
- Раунд идёт, только если в каждой команде есть хотя бы один игрок. Если команда опустела —
  раунд прерывается и начнётся заново, когда игроки появятся.
- Карта **«Городок»**: главная улица и поперечная, два квартала с каждой стороны, дома с дверями и
  окнами (в двухэтажные — по пандусу, ступенек у бойца пока нет), дворы с заборами 0.8 м
  (перепрыгиваются), развалины, магазин, поля со стогами, базы-фермы. Карта симметрична поворотом
  на 180° — у команд одинаковые условия. Игровая зона 152 × 88 м, края — невидимые стены.

## Игра по сети (v0.1)
- До **6 игроков**. Порт **7777** (UDP). Хост = сервер: он создаёт игру, остальные подключаются к его IP.
- **Radmin VPN**: все в одной сети Radmin; друзья вводят адрес хоста вида `26.x.x.x`
  (хост видит свои адреса в главном меню и в меню по Esc). Можно указать порт: `26.1.2.3:7777`.
- При первом «Создать игру» Windows спросит про брандмауэр — **разрешить** (частные сети).
- У всех должна быть **одна версия игры** (поле `config/version` в `project.godot`), иначе хост отключит с сообщением.
- Если игрок вылетел или у него пропала сеть — его боец исчезнет у остальных примерно через 8 секунд.

### Проверка на одном ПК (два окна)
*Debug → Customize Run Instances…* → включить *Enable Multiple Instances*, 2 копии, в *Launch Arguments*:
- копия 1: `--host --name=Хост --team=1`
- копия 2: `--join=127.0.0.1 --name=Гость --team=2`

F5 запустит оба окна сразу в бой, без меню. Аргументы: `--host`, `--join=IP`, `--name=Имя`, `--port=7777`,
`--team=1|2|0` (сразу выбрать команду, 0 — авто; без него — экран выбора),
для хоста: `--map=town|test_range`, `--kills=30`, `--round-time=600` (секунды), `--results-time=15`.

## Управление (v0.1)
| Клавиша | Действие |
|---|---|
| W A S D | движение |
| Shift | бег (только вперёд, только стоя) |
| C или Ctrl | присед (зажать) |
| Space | прыжок (из приседа — встать) |
| Мышь | обзор |
| ЛКМ | стрелять (автоматический огонь, пока зажата) |
| ПКМ | прицелиться (зажать) |
| R | перезарядка |
| Tab | таблица команд и счёт (зажать) |
| Esc | меню: продолжить / сменить команду / выйти в меню / выйти из игры |
| F3 | отладочная информация (в т.ч. пинг) |

Клавиши привязаны к **физическим** кнопкам — работают и на русской раскладке.

## Структура
Папки по **фичам**: сцена, её скрипт и её ресурсы лежат рядом.

```
project.godot
net/               network.gd — автозагрузка Network: хост/клиент, список игроков
match/             match.tscn — сцена боя: карта (грузится по настройкам) + бойцы
                   (MultiplayerSpawner) + правила + UI; tdm_rules.gd — команды, счёт, раунды;
                   match_settings.gd — карта и лимиты, список карт
player/            боец: player.tscn, player.gd (движение, сеть, здоровье, смерть, респавн)
weapons/           оружие: weapon_data.gd (параметры), rifle_ak.tres (АК),
                   weapon_controller.gd (стрельба/перезарядка/прицел/отдача),
                   bullet_manager.gd (полёт пуль), hit_math.gd (хитбоксы),
                   greybox_gun.gd (временная модель автомата)
maps/
  town/            «Городок» — карта для боя (greybox, СОЗДАЁТСЯ ГЕНЕРАТОРОМ, см. tools/)
  test_range/      полигон для проверки движения (greybox), 6 точек спавна
tools/             gen_town.gd — генератор карты «Городок»
shared/
  greybox/         общий greybox-материал (сетка 1 м / 5 м)
  audio/           временные звуки, сгенерированные кодом (до настоящих ассетов)
tests/             автотест боя (запускается только с аргументом --test=…)
ui/
  main_menu/       главное меню
  pause_menu/      меню по Esc
  net_hud/         «Подключение…», лента входа/выхода
  tdm_hud/         счёт команд и таймер, баннеры, таблица по Tab, экран итогов раунда
  team_select/     экран выбора команды
  combat_hud/      прицел, хитмаркер, индикатор урона, HP, патроны, лента убийств, экран смерти
  debug_overlay/   F3-оверлей
assets/            сторонние бесплатные ассеты (модели, звуки) — список в ASSETS.md
```

### Карта «Городок» и генератор
`maps/town/town.tscn` собирается скриптом `tools/gen_town.gd` из CSG-блоков:
```
godot --headless --path . --script res://tools/gen_town.gd
```
Сцену можно править и руками в редакторе, но **повторный запуск генератора её перезапишет** —
поэтому правим что-то одно. Точки спавна — `Marker3D` в группах `spawn_team_1` / `spawn_team_2`.
Невидимые стены по краям — на слое 3 (его видят бойцы, но не пули).

## Как устроена сеть
- **Хост авторитарен** для правил: кто в игре, спавн бойцов, (дальше) попадания и урон.
- **Движение — у владельца** (решение 17): каждый двигает своего бойца сам и 30 раз в секунду
  рассылает состояние через `MultiplayerSynchronizer` (через хост). Остальные показывают чужого
  бойца с задержкой 0.1 с, плавно между снимками (`Player._apply_remote_state`).
- Сцена матча загружается **до** подключения — так пакеты о бойцах никогда не приходят раньше карты.

## Как устроен бой
- **Пули настоящие**: летят со скоростью 715 м/с, падают под гравитацией, каждый тик физики
  проверяется отрезок полёта (`BulletManager`). Hitscan нет.
- Стрелок пускает пулю у себя (для вида) и сообщает хосту «выстрелил отсюда туда».
  Хост пускает **настоящую** пулю: только она наносит урон.
- **Компенсация пинга**: хост помнит, где был каждый боец последние 0.6 с, и проверяет пулю
  стрелка-клиента по бойцам «в прошлом» — на величину пинга этого клиента (до 0.3 с).
  Поэтому попадание засчитывается туда, куда игрок реально целился на своём экране.
- **Хитбоксы** считаются математикой (`HitMath`): голова — шар, тело — капсула; урон в голову ×1.8.
- Здоровье, «жив/мёртв», убийства, смерти и команду рассылает хост (`HostSync` в `player.tscn`).
- Смерть → 5 с → хост выбирает точку на базе команды (свободную и подальше от врагов) →
  боец появляется с полным здоровьем и патронами.
- Правила TDM (`TdmRules`) считает хост и рассылает состояние целиком: команды, счёт, фаза, таймер.
- Карту выбирает хост; клиент узнаёт её сразу после подключения и только тогда загружает.
- **Столкновения бойцов — мягкие**: бойцы не проходят друг сквозь друга, а плавно расталкиваются
  (`Player._get_separation_velocity`). Жёстких нет специально: чужой боец показан с задержкой 0.1 с,
  об него бы застревали, а товарищ мог бы «запереть» дверь.

### АК (стартовые параметры, `weapons/rifle_ak.tres`)
600 выстр/мин, магазин 30 + 120 в запасе, урон 25 → 18 (40–120 м), в голову ×1.8.
Смерть: 4 попадания в тело или 3 в голову. Перезарядка 2.2 с (пустой магазин — 2.7 с).
Все числа правятся в инспекторе Godot (открыть `.tres`).

### Автотесты
```
# бой: стрелок и мишень в разных командах
godot --headless --path . --host --name=A --team=1 --map=test_range --test=shooter
godot --headless --path . --join=127.0.0.1 --name=B --team=2 --test=target
godot --headless --path . --host --team=1 --map=test_range --test=ballistics

# TDM: огонь по своим, конец раунда по лимиту, итоги, новый раунд (3 копии)
godot --headless --path . --host --name=A --team=1 --map=test_range --kills=2 --results-time=4 --test=tdm_shooter
godot --headless --path . --join=127.0.0.1 --name=B --team=1 --test=tdm_mate
godot --headless --path . --join=127.0.0.1 --name=C --team=2 --test=tdm_enemy

# карта: точки спавна и подъём по пандусам (+ скриншоты с --screens=папка, без --headless)
godot --headless --path . --host --team=1 --map=town --test=town
```
Мишень стоит, бегает, затем подставляет голову; стрелок целится сам и печатает попадания.

## Соглашения по коду
- Строгая типизация везде. Нетипизированная переменная — **ошибка** (настроено в Project Settings → Debug → GDScript).
- Файлы и папки — `snake_case`, классы — `PascalCase` (`class_name Player`).
- Приватные поля и методы начинаются с `_`.
- Комментарии и документация — на русском.
- Сеть: хост авторитарен; код, который двигает бойца, проверяет `is_multiplayer_authority()`.
- Файлы `*.uid` и `*.import` коммитим (так рекомендует Godot 4.4+), папку `.godot/` — нет.
